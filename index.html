About Me

Hey, I'm Jeremy, a third-year Computer Science student at Wilfrid Laurier University focused on defensive security. I learn by building: home labs that use the same tools security analysts use every day, like Splunk, Nessus, Wireshark, pfSense and AWS CloudTrail.

In each lab I set up the environment, simulate an attack, build a detection or fix, and check that it actually works. I care about understanding why systems fail, not just that they do.

I'm working toward CompTIA Network+ and Security+, and I'm looking for a Summer 2027 internship or co-op where I can contribute to a real security or IT team.

SSH Brute Force Detection & Alerting

Simulated an SSH brute-force attack from Kali with a Python script, forwarded the Ubuntu auth logs to Splunk, and built a threshold-based correlation search that alerts on repeated failed logins from one source (MITRE ATT&CK T1110).

Network Security

Virtual Network Vulnerability Assessment

Segmented a lab network behind a default-deny pfSense firewall and scanned Windows and Ubuntu targets with Nessus from Kali. Blocked unneeded services such as SMB, then re-scanned to confirm the related findings were gone, verifying with Nmap and Wireshark.
